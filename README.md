# jev-superpowers-zh

jev-superpowers-zh 是以 [superpowers-zh](https://github.com/jnMetaCode/superpowers-zh) 的完整中文方法论与 26 款工具分发为底座、叠加 6 个汉化 [jev-superpowers](https://github.com/AkashPriyadarshii/jev-superpowers) 门禁技能的中文整合项目，共同方法论上游为 [obra/superpowers](https://github.com/obra/superpowers)。

## 状态

**v0.1.0 整合开发中**：当前仅建立包骨架、配置模板、双上游基线与元数据测试；技能、安装器、钩子与门禁运行时尚未迁入，暂不可安装使用。首期完整范围见 [RELEASE-NOTES.zh.md](RELEASE-NOTES.zh.md)。

## 上游归属

- [obra/superpowers](https://github.com/obra/superpowers) —— 共同方法论上游
- [jnMetaCode/superpowers-zh](https://github.com/jnMetaCode/superpowers-zh) —— 中文方法论与安装器底座
- [AkashPriyadarshii/jev-superpowers](https://github.com/AkashPriyadarshii/jev-superpowers) —— 门禁技能与本地决策层来源
